# 技术角色与任务领域体系

系统只保留三个宽口径角色：

- **开发工程师**：负责应用开发、AI、数据、质量、系统集成和产品体验类任务。
- **运维工程师**：负责中间件、云平台、交付和可观测性类任务。
- **网络工程师**：负责网络连接、安全、防火墙和相关云网络任务。

系统权限与技术角色相互独立。`Admin` 代表管理权限，技术角色仅用于任务匹配。每位成员只选择一个技术角色，不再区分主角色、兼任角色或能力等级。

任务采用十一个领域：软件与应用开发、AI 与智能系统、数据与数据库、中间件与平台、云原生与交付、网络与连接、安全与合规、质量与验证、可观测性与故障、系统集成与自动化、产品与用户体验。

角色与领域只保留“匹配/不匹配”关系，不再区分主要负责、支持协作和评审类型。角色匹配到任务领域后，该角色下所有可用成员都会进入通知名单。

管理员发布任务时只选择一个任务领域。系统从服务端计算提醒人员，不接受前端直接提交手机号。休假、停用、无手机号的成员不会被动态 `@`。

控制台“人员与角色管理”支持修改姓名、企业微信手机号、状态和单一技术角色。手机号规范化后使用 AES-256-GCM 加密保存。
