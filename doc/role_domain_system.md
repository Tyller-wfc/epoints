# 技术角色与任务领域体系

系统内置开发工程师、智能应用工程师、数据工程师、运维工程师、网络工程师、安全工程师、质量工程师、集成工程师和产品体验工程师九类宽口径角色。

系统权限与技术角色相互独立。`Admin` 代表管理权限，技术角色用于任务匹配。每位成员可以有一个主角色和多个兼任角色，每个角色记录 L1-L4 能力等级。

任务采用十一个领域：软件与应用开发、AI 与智能系统、数据与数据库、中间件与平台、云原生与交付、网络与连接、安全与合规、质量与验证、可观测性与故障、系统集成与自动化、产品与用户体验。

角色与领域通过 `P/S/R` 多对多关联：`P` 为主要负责并默认在企业微信中 `@`；`S` 为支持协作；`R` 为评审角色。

管理员发布任务时必须选择一个主领域，可以选择多个次要领域。系统从服务端计算提醒人员，不接受前端直接提交手机号。休假、停用、无手机号的成员不会被动态 `@`。

控制台“人员与角色管理”支持修改姓名、企业微信手机号、状态、主角色、兼任角色和能力等级。手机号规范化后使用 AES-256-GCM 加密保存。
