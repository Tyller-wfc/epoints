# 企业微信提醒配置与使用

## 功能范围

ePoints 使用企业微信“消息推送”（原群机器人）Webhook 发送提醒。发布新项目任务，以及新建任意级别的系统故障工单时，都会自动推送到企业微信群。

任务消息包含任务名称、分类、基础积分、奖励倍率、发布人和任务描述。故障消息包含故障等级、标题、上报人、当前值班负责人、故障描述和响应要求。配置手机号后，消息会通过 `mentioned_mobile_list` 提醒对应群成员。

## 一、在企业微信群创建机器人

1. 在企业微信桌面端或手机端进入用于接收故障提醒的内部群聊。
2. 打开群设置，选择“群机器人”，再选择“添加机器人”。
3. 输入名称，例如“ePoints 故障提醒”，并完成添加。
4. 复制机器人提供的 Webhook 地址。地址格式必须是：

   `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

5. 不要把该地址发到公开聊天、提交到 Git 或写入前端环境变量。URL 中的 `key` 等同于发送凭据。

如果群设置中没有“群机器人”，需要由企业微信管理员确认当前企业、群类型及机器人能力是否可用。

## 二、在 ePoints 中启用

1. 启动 NestJS 后端和 React 前端，使用管理员账号登录 ePoints（初始账号为 `u2`，即王方超）。
2. 进入“控制台”。
3. 找到“企业微信群机器人提醒”。
4. 将完整 Webhook 粘贴到“群机器人 Webhook”。
5. 在“需要 @ 的手机号”中填写企业微信成员绑定的手机号。多个号码用逗号、空格或分号分隔。
6. 点击“保存配置”。保存后页面只显示 Webhook 的末六位，完整密钥不会返回浏览器。
7. 点击“发送测试消息”。只有企业微信返回 HTTP 成功且响应体 `errcode` 为 `0`，页面才会显示发送成功。

## 三、验证自动提醒

1. 进入“技术保障中心”。
2. 填写故障标题和描述。
3. 选择故障严重级别；所有级别都会推送，`Critical` 会使用红色警报标题和 10 分钟接单要求。
4. 提交故障。
5. 企业微信群应收到“ePoints Critical 红色警报”，配置的群成员会被提醒。

工单创建和群通知相互独立。企业微信暂时不可用时工单仍会创建，系统动态中会追加“企业微信通知失败”记录，后端日志会保留具体错误。

## 四、修改与停用

- 只修改提醒手机号：Webhook 输入框留空，修改手机号后保存。
- 更换机器人：粘贴新的完整 Webhook 后保存，再发送测试消息。
- 停用提醒：点击“停用提醒”。之后 Critical 工单只在 ePoints 页面中显示红色警报。

## 常见问题

- `请输入有效的企业微信群机器人 Webhook 地址`：只接受 HTTPS、域名 `qyapi.weixin.qq.com`、路径 `/cgi-bin/webhook/send` 且带 `key` 参数的地址。
- `提醒手机号格式不正确`：手机号只能包含数字，可选一个开头的 `+`，多个号码需要分隔。
- 企业微信返回非零 `errcode`：通常是机器人被移除、key 无效、机器人能力受限或请求频率受限。重新复制 Webhook 并使用测试按钮查看准确错误。
- 页面提示成功但没有 `@`：确认手机号已绑定到目标企业微信成员，并且该成员在接收提醒的群中。
- 请求超时：后端等待企业微信最多 8 秒；检查服务器能否访问 `qyapi.weixin.qq.com:443`。

## 服务端接口

- `POST /api/settings/wecom`：保存或停用配置。
- `POST /api/settings/wecom/test`：由后端发送测试消息并校验企业微信返回值。
- Webhook 地址保存在 `settings.webhook_url`，提醒手机号保存在 `settings.webhook_mention_mobiles`。
